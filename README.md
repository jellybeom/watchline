# watchline

영웅문4 차트에 그어둔 수평선 가격을 읽어, 관심종목 CSV에 자동으로 채워 넣는 편집기입니다.
기준봉 날짜와 태그는 달력·체크박스로 입력하고, 결과는 원본 CSV에 그대로 덮어씁니다.

기존에는 차트의 선 가격을 눈으로 읽어 엑셀에 옮겨 적어야 했습니다.
이 도구는 그 과정을 없애고, 사람이 판단해야 하는 값(기준봉·태그)만 입력받습니다.

---

## 동작 방식

영웅문4의 차트 작도 데이터는 서버가 아니라 **로컬 파일에만** 저장됩니다.
키움 OpenAPI로는 가져올 수 없으므로, 설치 폴더의 작도 파일을 직접 읽습니다.

```
C:\KiwoomHero4\user\#계정폴더$\660000_2$dr@044490_0.cs5
                                └ 화면번호 ┘ └종목┘ └주기
```

이 파일은 CP949 INI 형식이며, 섹션 하나가 작도 객체 하나입니다.
수평선은 `분석도구유형=20`이고 가격은 `시작값` 필드에 들어 있습니다.
(`종료값`·`추가값`은 마우스 좌표에서 파생된 내부 잔여값이라 사용하지 않습니다.)

> **작도 파일은 주기 전환 시점이나 HTS 종료 시에만 디스크에 기록됩니다.**
> 실행 전에 영웅문4를 종료하는 것이 가장 안전합니다.
> 켜둔 채로 쓰려면 차트 환경설정 → 차트속성에서 '추세선 저장'이 켜져 있어야 하고,
> 선을 그은 뒤 일봉↔주봉을 한 번 전환해야 저장됩니다.

## 설치

[uv](https://docs.astral.sh/uv/)가 필요합니다.

```powershell
# uv 설치 (한 번만)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 의존성 설치
uv sync
```

`watchline/config.py`를 열어 `hero_user_root`를 실제 설치 경로로 맞추면 준비가 끝납니다.
설정은 전부 이 파일 하나에 있습니다.

## 사용법

`run.bat`을 더블클릭하거나:

```powershell
uv run watchline                 # 편집기 실행
uv run watchline path\to.csv     # 파일을 지정해 실행
uv run watchline-report          # 수평선 추출 결과만 터미널에 출력
```

### 저녁 작업 흐름

1. 영웅문4에서 관심종목을 CSV로 내보냅니다.
2. 영웅문4를 종료합니다.
3. `run.bat` 실행 → 파일을 창 안으로 끌어다 놓습니다(`Ctrl+O`도 됩니다).
4. 1~3선이 자동으로 채워집니다. 붉게 표시된 행은 확인이 필요한 종목입니다.
5. 기준봉 셀을 더블클릭하면 달력이 뜹니다. 태그는 체크박스를 클릭합니다.
6. `Ctrl+S`로 저장하면 원본 파일에 덮어써집니다.

### 여러 파일 합치기

입력이 여러 개여도 **결과는 파일 하나**입니다. 파일을 두 개 이상 끌어다 놓으면
첫 파일 아래에 다음 파일의 행이 이어붙고, 이미 목록이 있는 상태에서 더 놓아도
같은 방식으로 더해집니다.

종목코드가 겹치면 **먼저 들어온 쪽을 남기고 건너뜁니다.** 어느 종목이 중복이었는지는
로그에 표시됩니다. 열 구성은 첫 파일을 따르며, 파일마다 열이 다르면 경고를 남깁니다.

'열기'는 새 목록으로 시작하고, 드래그 앤 드롭은 현재 목록에 더합니다.

### KOSPI 장 구분 자동 태그

매일 장이 끝난 뒤(기본 20시 이후) 그날 KOSPI가 상승장이었는지 하락횡보장이었는지를
'KOSPI 기록' 창에서 입력해 둡니다. 그러면 각 종목의 **기준봉 날짜에 해당하는 장 구분**이
`#KOSPI상승장` 또는 `#KOSPI하락횡보장` 태그로 자동으로 붙습니다.

적용 시점은 세 가지입니다. 파일을 열 때, 기준봉을 입력하거나 지울 때, 그리고
'KOSPI 새로고침'을 누를 때입니다.

기존 KOSPI 태그를 떼고 다시 붙이는 방식이라, **잘못 기록한 날을 고친 뒤 새로고침하면
해당 종목들의 태그가 한 번에 교정됩니다.** 나머지 태그는 건드리지 않습니다.
기준봉이 비어 있거나 그 날짜의 기록이 없으면 KOSPI 태그를 붙이지 않습니다.

기록은 `kospi.json`에 날짜 순으로 저장됩니다. 값은 태그 문자열이 아니라 `up`/`down`이라,
`tags.txt`에서 태그 이름을 바꿔도 과거 기록이 깨지지 않습니다.

```json
{
  "2026-08-06": "up",
  "2026-08-07": "down"
}
```

### 기준봉·태그 가져오기

새로 내보낸 파일에는 기준봉과 태그가 비어 있습니다. 어제 저장한 파일을 지정하면
**종목코드로 짝을 맞춰 기준봉과 태그만** 옮겨옵니다.

가격·등락률·메모 등 원본 열과 1~3선은 절대 바뀌지 않습니다. 또한 현재 파일에
이미 값이 들어 있는 항목은 덮어쓰지 않고 그대로 두며, 몇 건을 채우고 몇 건을
남겼는지 로그와 알림창에 표시합니다.

### 단축키와 편의 기능

| 기능                 | 위치           | 설명                                                  |
| -------------------- | -------------- | ----------------------------------------------------- |
| 열기                 | `Ctrl+O`       | 새 목록으로 엽니다. 여러 개를 고르면 합쳐집니다       |
| 저장                 | `Ctrl+S`       | 저장 위치를 물어봅니다. 같은 이름을 고르면 덮어씁니다 |
| 3선 새로고침         | `F5`           | HTS에서 선을 고친 뒤 사용합니다                       |
| 기준봉·태그 가져오기 | 툴바           | 이전에 저장한 파일에서 기준봉과 태그만 옮겨옵니다     |
| KOSPI 기록           | 툴바           | 날짜별 장 구분을 추가·수정·삭제합니다                 |
| KOSPI 새로고침       | `F6`           | 기록을 다시 읽어 KOSPI 태그를 붙입니다                |
| 기준봉 오늘로        | 우클릭         | 선택한 행 전체를 오늘 날짜로                          |
| 기준봉 삭제          | 우클릭         | 선택한 행 전체의 기준봉을 비웁니다                    |
| 태그 복사            | 우클릭         | 한 행만 선택했을 때 나타납니다                        |
| 태그 붙여넣기        | 우클릭         | 복사한 태그를 선택한 행 전체에 적용                   |
| 태그 켜기/끄기       | 클릭 · `Space` | 셀 어디를 눌러도 바뀝니다                             |

시장 상황 태그처럼 그날 전 종목이 같은 값이라면, 한 종목에 태그를 달고 복사한 뒤
나머지를 모두 선택해 붙여넣는 것이 빠릅니다.

## 검사 규칙

아래에 해당하는 종목은 **1~3선을 채우지 않고** 붉게 표시합니다.
사유는 셀에 마우스를 올리면 툴팁으로 뜹니다. 판단이 필요한 경우이므로 자동으로 처리하지 않습니다.

| 사유             | 설명                                                                      |
| ---------------- | ------------------------------------------------------------------------- |
| 수평선 부족      | 해당 종목의 수평선이 3개 미만                                             |
| 여러 화면에 작도 | 같은 종목이 둘 이상의 차트 화면에 그려져 있어 어느 쪽이 맞는지 알 수 없음 |

### 가격분포 경고

`1선↔3선` 열은 1선 대비 3선이 몇 % 낮은지 보여줍니다. 통상 7~9%이며,
`spread_limit`(기본 10%)를 넘으면 붉게 표시합니다. 의도치 않은 고가 수평선이
섞여 1선이 밀려 올라갔을 가능성이 큽니다.

이 종목은 **제외하지 않고 값을 채워 넣습니다.** 1~3선 셀은 직접 수정할 수 있으므로,
표에서 값을 고치면 낙폭이 즉시 다시 계산됩니다. HTS에서 선을 지운 뒤
`F5`로 새로고침해도 됩니다.

### 자동 처리 (로그에만 남김)

- 수평선이 4개 이상이면 **가격이 높은 순으로 3개**를 선택
- 가격이 정수가 아니면 **소수점을 버리고 내림**
- 같은 가격의 중복 수평선은 하나로 합침
- 일봉(`_0`) 외 주기의 작도 파일은 무시
- 수평선(`분석도구유형=20`) 외의 작도는 무시

## 파일 형식

### 입력 — 영웅문4 관심종목 내보내기 (CP949)

```
분,신,종목명,현재가,등락률,L일봉H,거래대금,메모,종목코드
증,,GRT,"3,895",4.42,3840 3895 3625 3895,"1,040",,'900290
BLANK|,,,,,,,,
```

종목코드가 유효한 6자리(영문·숫자)인 행만 남기고, `BLANK|` 같은 빈 슬롯과
중복 행은 버립니다. 무엇이 왜 빠졌는지는 실행 로그에 표시됩니다.

### 출력 — 같은 파일에 5개 열 추가 (CP949)

```
...,종목코드,1선,2선,3선,기준봉,태그
...,'900290,3355,3215,3105,2026-07-31,
...,'025900,6320,6100,5900,2026-08-07,"""#KOSPI하락횡보장, #상한가"""
```

| 열              | 형식                                              |
| --------------- | ------------------------------------------------- |
| 1선 / 2선 / 3선 | 정수. 자릿수 구분 기호 없음. 1선이 가장 높은 가격 |
| 기준봉          | `YYYY-MM-DD`                                      |
| 태그            | 큰따옴표로 감싸고 `, `로 구분. 없으면 빈 칸       |

태그 셀은 **값 자체에 큰따옴표를 포함**합니다. CSV로 기록될 때 이스케이프되어
`"""#A, #B"""`가 되며, 이 형식은 다른 프로그램과 맞추기 위한 것입니다.

저장한 파일을 다시 열면 기준봉과 태그는 그대로 유지되고 1~3선만 갱신됩니다.
추출 결과가 없는 종목은 기존 값을 지우지 않습니다.

### 태그 목록 — `tags.txt`

한 줄에 하나씩 적습니다. 프로그램을 고치지 않고 태그를 늘리거나 줄일 수 있습니다.

```
#KOSPI상승장
#KOSPI하락횡보장
#시장을이기는종목
#상한가
#테마주
#섹터주
```

**줄 순서가 곧 저장 순서입니다.** 어떤 순서로 체크하든 이 파일의 순서대로 정렬되므로,
같은 태그 조합이면 항상 같은 문자열이 나옵니다.

## 안전장치

실제 매매에 쓰는 데이터를 덮어쓰므로 다음을 지킵니다.

- **저장 위치 확인**: 저장할 때마다 위치와 이름을 물어봅니다. 덮어쓰기는 사용자가 같은 이름을 골랐을 때만 일어나며, 그때도 운영체제가 한 번 더 확인합니다.
- **원자적 쓰기**: 임시 파일에 먼저 쓰고 교체하므로, 저장이 실패해도 원본은 손상되지 않습니다. 다른 프로그램이 반쯤 쓰인 파일을 읽는 일도 없습니다.
- **미입력 경고**: 기준봉이 빈 종목이 있으면 저장 전에 알려줍니다.
- **불확실하면 비움**: 수평선이 부족하거나 판단이 불가능한 종목은 추측한 값을 넣지 않고 비워 둡니다.

## 프로젝트 구조

```
watchline/
├── pyproject.toml       의존성 및 실행 명령 정의
├── run.bat              Windows 실행용
├── tags.txt             태그 목록 (수정 가능)
├── kospi.json           KOSPI 일별 장 구분 기록
├── watchline/
│   ├── config.py        경로와 판정 기준
│   ├── icon.ico         앱 아이콘 (원본: icon.svg)
│   ├── hlines.py        작도 파일 파싱 및 수평선 추출
│   ├── kospi.py         KOSPI 장 기록 저장 및 태그 적용
│   ├── kospi_dialog.py  KOSPI 기록 편집 창
│   ├── watchlist.py     관심종목 CSV 읽기/쓰기
│   ├── cli.py           터미널 리포트
│   └── ui.py            PySide6 편집기
└── tests/
    ├── conftest.py      CSV 예시 데이터 (코드로 생성)
    ├── test_hlines.py   추출 규칙
    ├── test_kospi.py    KOSPI 기록·태그
    └── test_watchlist.py  CSV 입출력
```

UI와 로직을 분리했습니다. `hlines`와 `watchlist`는 PySide6에 의존하지 않으므로
다른 프로그램에서 그대로 임포트할 수 있습니다.

```python
from watchline.hlines import extract
from watchline.watchlist import load, apply_lines, save

res = extract()
wl = load("관심종목.csv")
apply_lines(wl, res.lines)
save(wl)
```

## 문제 해결

설정은 모두 `watchline/config.py`에 있습니다.

**수평선이 하나도 안 읽힙니다**
HTS를 종료했는지, `hero_user_root`가 맞는지 확인하세요.
`uv run watchline-report`를 실행하면 '주기 인덱스 분포'가 나오는데,
`_0`이 아닌 인덱스만 있다면 `period_index`를 그 값으로 바꿔야 합니다.

**계정 폴더가 여러 개라고 나옵니다**
`hero_account_dir`에 사용할 폴더의 전체 경로를 직접 적으세요.

**차트 화면이 여러 개라고 나옵니다**
과거에 종합차트를 두 개 이상 띄워 쓰신 경우입니다.
`screen_prefix`에 사용할 화면번호(예: `"660000_2"`)를 지정하세요.

**한글이 깨집니다**
입출력 CSV는 CP949 고정입니다. 중간에 다른 프로그램이 UTF-8로 저장했다면
영웅문에서 다시 내보내세요.

**작도 파일 형식이 바뀐 것 같습니다**
`.cs5`는 비공개 형식이라 HTS 업데이트로 바뀔 수 있습니다.
`uv run watchline-report`의 '도구유형' 줄에 예상치 못한 코드가 보이면
`hline_type`을 조정해야 할 수 있습니다.
